Tether privacy policy

Last updated November 15, 2026.

Tether is a personal, single-user application. It is used only by its owner, to triage their own email, calendars and tasks. Only the owner can sign in, and only the owner's own Google accounts are connected.

Data Tether accesses

  • Gmail (gmail.modify): message metadata (sender, recipients, subject, date, labels) and snippets, to build an inbox list; labels, to archive and unarchive threads; and message content, fetched on request when the owner asks their assistant to read or search mail.
  • Google Calendar: events on calendars the owner selects, to merge them into one calendar in the owner's own account, and to create or update events when the owner asks.
  • Google sign-in: the email address and account ID, to confirm the owner is the one signing in.

What is stored

Tether stores message metadata, short snippets, links back to Gmail, calendar event details inside a rolling window, and the owner's own tasks. It does not store message bodies. OAuth tokens are encrypted at rest. Data is kept on a private server operated by the owner.

Sharing

Tether does not sell, share or transfer Google user data to anyone. Message content is passed to the owner's own AI assistant only when the owner's assistant requests it on the owner's behalf. No data is used for advertising.

Tether's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion

Disconnecting an account, or revoking Tether's access at myaccount.google.com/permissions, stops all access. The owner can delete all stored data at any time.

Contact

Use the support email shown on Tether's Google sign-in screen.
