Your inboxes, tasks and calendars in one place

Tether is a personal productivity app. It gathers its owner's Gmail inboxes, Google calendars, a work calendar and to-do list into one view, so nothing gets lost between accounts.

Sign in with Google

What Tether does

  • One inboxInbox threads from several Gmail accounts in one list, each marked with its account's color. Archive a thread in Tether and it is archived in Gmail.
  • One calendarEvents from the calendars the owner chooses, merged into one calendar with each event showing which calendar it came from. New events can be created on any of them.
  • TasksA to-do list, with tasks linked to the emails they came from.
  • An assistant's viewThe owner's AI assistant can read the same overview to help triage, only when the owner asks it to.

Who can use it

Tether is run by its owner, for the owner. It is not a public service: only the owner's own Google account can sign in, and only the owner's own accounts are connected. Anyone else who signs in is turned away.

How Tether uses Google data

Tether asks Google for these permissions when an account is connected, and uses each only as described:

PermissionWhat Tether does with it
Sign-in (openid, email)Confirms that the person signing in is the owner, and names each connected account.
Gmail (gmail.modify)Lists inbox threads (sender, subject, date and a short snippet), archives and unarchives threads when the owner asks, and shows a message's text when the owner opens it. Tether never sends or deletes email.
Calendar (calendar.readonly, calendar.events)Reads events from the calendars the owner selects to build the merged calendar, writes that merged calendar to one calendar in the owner's account, and creates events the owner makes in Tether.

Google data is never sold, shared with anyone else or used for advertising. Message bodies are not stored. The privacy policy has the details, and the terms of service say what using Tether means.
